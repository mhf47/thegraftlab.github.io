# The Graft Lab website

A free, static website for the Frank Lab at Cornell University. No Wix subscription, hosting fee, build tools, or dependencies are required.

## Publish on GitHub Pages

1. Open the public GitHub repository `thegraftlab/thegraftlab.github.io`.
2. Choose **Add file → Upload files**.
3. Upload `index.html` from this ZIP (not the ZIP itself). You may also upload this README.
4. Select **Commit changes**.
5. In **Settings → Pages**, under **Build and deployment**, choose **Deploy from a branch**. Set branch to `main` and folder to `/ (root)`, then save.
6. Wait a few minutes and visit https://thegraftlab.github.io/ (assuming the username is `thegraftlab`).

## Editing

`index.html` is a self-contained HTML file. To update it, replace the file in the repository and commit the change.

## Before sharing widely

- Review all copy, titles, and contact details.
- Replace the portrait placeholder and add lab member bios and images.
- Add selected publications and real lab news items.
- Confirm the repository name and GitHub Pages URL.

The botanical illustration is embedded as SVG, so no external images or libraries are required.
